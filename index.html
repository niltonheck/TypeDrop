Typed Recipe Box: Ingredient Scaling, Diet Filtering & Nutrition Rollup

You're building the recipe-management core for a meal-planning app. Users browse a typed recipe catalogue, filter recipes by dietary tags, scale ingredient quantities to a target serving count, and compute a typed nutrition summary — with the compiler enforcing every ingredient shape, diet tag, scaling result, and rollup field.

Goals

  • Define five strictly-typed interfaces (`NutritionInfo`, `Ingredient`, `Recipe`, `ScaledRecipe`, `NutritionSummary`) and the `DietTag` union with exactly the required members.
  • Implement `filterByDietTag` to return only recipes whose `dietTags` array includes the requested `DietTag`.
  • Implement `scaleRecipe` to proportionally scale ingredient quantities and compute total nutrition for `targetServings`, throwing a `RangeError` for invalid input.
  • Implement `computeNutritionSummary` to aggregate `scaledNutrition` fields across an array of `ScaledRecipe` objects into a typed summary with correct totals and average.

Hints

  • The `DietTag` union should use string literal types — the compiler will then reject any typo passed to `filterByDietTag` at the call site.
  • For `scaleRecipe`, compute a single `factor = targetServings / recipe.servings` and apply it to every ingredient quantity and every `NutritionInfo` field — `Math.round(value * 100) / 100` gives 2 d.p. without `toFixed`.
  • In `computeNutritionSummary`, a single `Array.reduce` pass can accumulate all four nutrition totals at once; compute `averageCalories` after the loop using a ternary guard for the empty-array case.
