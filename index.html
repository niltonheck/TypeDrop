Typed Event Analytics Aggregator

You're building the analytics engine for a SaaS dashboard. Raw events stream in from the client SDK — page views, button clicks, form submissions, and errors — and your job is to parse, validate, and aggregate them into a per-session summary report, with the compiler enforcing every event shape, aggregation field, and result type with no escape hatches.

Goals

  • Define `EventOfKind<K>` as a conditional/utility type derived purely from `AnalyticsEvent` using `Extract` — no manual mapping.
  • Implement `parseEvent` to validate an `unknown` value into a `ParseResult<AnalyticsEvent>` using type narrowing only — no `any` or type assertions.
  • Implement `aggregateEvents` to parse, group by session, and compute each `SessionSummary` in a single pass, returning a sorted `AggregationReport`.
  • Implement `filterByKind` with a type predicate so the returned array is narrowed to the exact `EventOfKind<K>` subtype.

Hints

  • For `EventOfKind<K>`, try `Extract<AnalyticsEvent, { kind: K }>` — `Extract` picks union members assignable to the second argument.
  • In `parseEvent`, use a `typeof` / `in` guard first to confirm `raw` is a non-null object before reading any properties; then switch on `raw.kind` to handle each variant.
  • For the single-pass accumulator in `aggregateEvents`, initialise every counter to 0 / ±Infinity before the loop and update them with `if` checks inside one `for...of`.
