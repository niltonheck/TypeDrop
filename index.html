Typed Contact Book: Search, Tag Filtering & vCard Export

You're building the core logic for a personal contact management app. Users store contacts with typed fields, filter them by tags, search by name or email, and export individual contacts as a formatted vCard string — with the compiler enforcing every contact shape, filter predicate, and export field.

Goals

  • Define all required union types, the Contact interface (with optional fields), SearchQuery, and the VCardField mapped type.
  • Implement searchContacts so it correctly filters by name substring, email substring, and all-tags-must-match logic.
  • Implement formatVCard to produce a spec-compliant vCard 3.0 string, conditionally including company and birthday lines.
  • Implement groupByTag so every ContactTag key is always present in the result and contacts appear under each of their tags.
