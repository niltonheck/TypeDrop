Typed Library Book Checkout Tracker

You're building the checkout desk software for a public library. Books are checked out and returned by members, and you need to track availability, compute overdue fines, and produce a per-member borrowing summary — with the compiler enforcing every status, field name, and summary shape.

Goals

  • Implement `isOverdue` as a proper type-predicate guard that narrows `Book` to `CheckedOutBook`.
  • Implement `calculateFine` using discriminated-union narrowing to return the correct dollar amount for available, checked-out, and lost books.
  • Implement `buildLibraryReport` to aggregate per-member statistics (counts, fines, overdue titles) into a sorted `LibraryReport`.
  • Use branded types (`ISBN`, `MemberID`) throughout without casting to plain `string`.
challenge.ts 
// Key types and main function signatures at a glance

type ISBN   = string & { readonly __brand: "ISBN" };
type MemberID = string & { readonly __brand: "MemberID" };

type Book =
  | { status: "available";  isbn: ISBN; title: string; author: string }
  | { status: "checkedOut"; isbn: ISBN; title: string; author: string;
      memberId: MemberID; dueDate: string }
  | { status: "lost";       isbn: ISBN; title: string; author: string;
      memberId: MemberID };

type FinePolicy = { overduePerDay: number; lostFlatFee: number };

type MemberSummary = {
  memberId: MemberID;
  checkedOutCount: number;
  lostCount: number;
  totalFinesDue: number;      // rounded to 2 decimal places
  overdueTitles: string[];
};

// --- Functions you must implement ---
function isOverdue(book: Book, today: string): book is CheckedOutBook;
function calculateFine(book: Book, today: string, policy: FinePolicy): number;
function buildLibraryReport(books: Book[], today: string, policy: FinePolicy): LibraryReport;
Hints (click to reveal)

Hints

  • A type predicate has the form `book is CheckedOutBook` — you must check `book.status === 'checkedOut'` AND compare ISO date strings before returning `true`.
  • For day-difference arithmetic between two ISO date strings, `(new Date(a).getTime() - new Date(b).getTime()) / 86_400_000` gives calendar days as a float — `Math.floor` it.
  • Use a `Map<MemberID, MemberSummary>` (or a plain object keyed by `MemberID`) to accumulate per-member data in a single pass through the `books` array.
