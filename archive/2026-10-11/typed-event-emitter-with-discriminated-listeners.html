Typed Event Emitter with Discriminated Listeners

You're building the notification layer for a real-time dashboard. UI components subscribe to named events, and the compiler must guarantee that every listener receives exactly the payload shape its event name implies — no runtime surprises, no casting.

Goals

  • Define `EventMap` as an index signature interface and extend it with the concrete `DashboardEventMap` entries.
  • Implement `TypedEmitter<TMap>` so that `on`, `off`, `emit`, `once`, and `listenerCount` are all generic over `keyof TMap`, binding each event name to its exact payload type.
  • Make `once` auto-deregister its wrapper listener after the first invocation, keeping `listenerCount` accurate.
  • Implement the `createEmitter` factory as a generic function that constructs and returns a `TypedEmitter<TMap>` without any type assertions.
challenge.ts 
// Key types + main class signature at a glance

export interface EventMap {
  [event: string]: unknown;
}

export type Listener<TPayload> = (payload: TPayload) => void;

export interface DashboardEventMap extends EventMap {
  userLoggedIn:   { userId: string; timestamp: number };
  metricUpdated:  { metricName: string; value: number; unit: string };
  alertTriggered: { alertId: string; severity: "low" | "medium" | "high"; message: string };
  sessionExpired: { sessionId: string };
}

export class TypedEmitter<TMap extends EventMap> {
  on<K extends keyof TMap>(event: K, listener: Listener<TMap[K]>): void { /*...*/ }
  off<K extends keyof TMap>(event: K, listener: Listener<TMap[K]>): void { /*...*/ }
  emit<K extends keyof TMap>(event: K, payload: TMap[K]): void { /*...*/ }
  once<K extends keyof TMap>(event: K, listener: Listener<TMap[K]>): void { /*...*/ }
  listenerCount<K extends keyof TMap>(event: K): number { /*...*/ }
}

export function createEmitter<TMap extends EventMap>(): TypedEmitter<TMap> { /*...*/ }

Hints

  • Store listeners in a `Map<keyof TMap, Set<Listener<TMap[keyof TMap]>>>` — but think carefully about how to cast keys safely inside the class without using `any`.
  • For `once`, create an internal wrapper function that calls `off` on itself before invoking the original listener — store the wrapper, not the original, in the listeners map.
  • The `keyof TMap` constraint on every method is what ties the event name to its payload: `K extends keyof TMap` means `payload: TMap[K]` is always the right type at each call site.
