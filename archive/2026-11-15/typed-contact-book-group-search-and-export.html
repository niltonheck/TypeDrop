Typed Contact Book: Group, Search & Export

You're building the core logic for a personal contact-book app. Contacts are stored with typed fields, can belong to labelled groups, and must be searchable by name or email and exportable to a simple vCard-style string — with the compiler enforcing every field shape, search result, and export format.

Goals

  • Implement `groupContacts` using `Record<GroupLabel, Contact[]>`, ensuring all four keys are always present and contacts with empty groups fall into 'other'.
  • Implement `searchContacts` with case-insensitive substring matching and return the `ContactSummary` Pick type — not full Contact records.
  • Implement `exportVCard` to produce a correctly formatted vCard 3.0 string, uppercasing phone types and conditionally including the BDAY line.
  • Implement `mergeContacts` to produce a valid `Contact` by preferring non-empty override scalars, unioning phone arrays, and de-duplicating group arrays.
challenge.ts 

// Key types you'll work with:

export type GroupLabel = "family" | "work" | "friend" | "other";

export interface Contact {
  readonly id: string;
  readonly firstName: string;
  readonly lastName: string;
  readonly email: string;
  readonly phones: ReadonlyArray<{ type: "mobile" | "home" | "work"; number: string }>;
  readonly groups: ReadonlyArray<GroupLabel>;
  readonly birthday?: string;
}

export type ContactSummary   = Pick<Contact, "id" | "firstName" | "lastName" | "email">;
export type GroupedContacts  = Record<GroupLabel, Contact[]>;

// The four functions you must implement:
export function groupContacts(contacts: Contact[]): GroupedContacts;
export function searchContacts(contacts: Contact[], query: string): ContactSummary[];
export function exportVCard(contact: Contact): string;
export function mergeContacts(base: Contact, override: Contact): Contact;
Hints (click to reveal)

Hints

  • For `groupContacts`, seed your result object with all four `GroupLabel` keys before iterating — `Record<GroupLabel, Contact[]>` requires every key to be present.
  • For `mergeContacts`, a simple `override.field.length > 0 ? override.field : base.field` pattern handles the non-empty-string preference without needing `any` or type assertions.
  • For `exportVCard`, build an array of lines, conditionally push the BDAY line using the optional `birthday` field, then join with '\n' at the end.
