Typed Contact Directory Merger

You're building the import tool for a small-business CRM. Contacts arrive from two sources — an internal database and a CSV export — and you need to merge them, resolve duplicates by email, normalize phone formats, and produce a typed directory summary the compiler fully enforces.

Goals

  • Implement `normalizePhone` so it returns the branded `NormalizedPhone` template-literal type or `null` — without any type assertions.
  • Implement `liftContact` and `mergeContacts` to produce fully-typed `MergedContact` objects with correct source preference, null-coalescing, and completeness classification.
  • Implement `buildDirectory` to group contacts by email, delegate to `liftContact` or `mergeContacts`, throw on same-source duplicates, and return a correctly shaped `DirectorySummary`.
  • Ensure `bySource` and `byCompleteness` in the summary use `Record<ContactSource, number>` and `Record<CompletenessLevel, number>` so every key is always present.
challenge.ts 
export type ContactSource = "internal" | "csv";
export type NormalizedPhone = `+1${string}`;
export type CompletenessLevel = "full" | "partial" | "minimal";

export interface RawContact {
  readonly source: ContactSource;
  readonly name: string;
  readonly email: string;
  readonly phone?: string;
  readonly accountId?: number;  // internal only
  readonly company?: string;    // csv only
}

export interface MergedContact {
  readonly name: string;
  readonly email: string;
  readonly phone: NormalizedPhone | null;
  readonly accountId: number | null;
  readonly company: string | null;
  readonly sources: ReadonlyArray<ContactSource>;
  readonly completeness: CompletenessLevel;
}

export function normalizePhone(raw: string): NormalizedPhone | null { ... }
export function liftContact(raw: RawContact): MergedContact { ... }
export function mergeContacts(a: RawContact, b: RawContact): MergedContact { ... }
export function buildDirectory(contacts: ReadonlyArray<RawContact>): {
  directory: Map<string, MergedContact>;
  summary: DirectorySummary;
} { ... }

Hints

  • To satisfy the `NormalizedPhone` template-literal type without `as`, write a helper that constructs the string and returns it with a type-predicate (`is NormalizedPhone`) or simply returns the correctly-prefixed string through a narrow typed path.
  • When picking fields in `mergeContacts`, check `a.source === 'internal'` to decide which variable holds `accountId` vs `company` — the compiler will narrow the optional fields for you.
  • For `buildDirectory`'s `bySource` count, iterate the final `MergedContact` values and increment a counter for each entry in `contact.sources` — merged records will increment both keys.
