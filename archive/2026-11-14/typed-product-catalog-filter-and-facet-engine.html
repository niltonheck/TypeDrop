Typed Product Catalog Filter & Facet Engine

You're building the search & browse layer for an e-commerce platform. Raw catalog entries arrive as `unknown` JSON, your engine must validate and narrow them into typed products, apply a composable set of typed filters, and produce a faceted result — with counts per category, price-range buckets, and availability flags — all enforced by the compiler with no escape hatches.

Goals

  • Implement `isProduct` as a strict type guard that narrows `unknown` to `Product` using only control-flow narrowing — no type assertions.
  • Implement `getPriceBucket` returning the correct `PriceBucket` literal union for any positive price.
  • Implement `applyFilter` composing all optional filter axes with AND logic between axes and OR logic within `categories`.
  • Implement `buildFacets` and `searchCatalog` to wire the full pipeline, producing a `FacetedResult` with accurate per-category, per-price-bucket, and stock counts over the filtered product list.

Hints

  • For `isProduct`, use `typeof`, `Array.isArray`, and an explicit `includes` check on a `const` array of valid Category values to narrow the category field without casting.
  • For `getPriceBucket`, a chain of `if/else if` with explicit `return` statements is enough for TypeScript to infer the `PriceBucket` return type — no assertion needed.
  • `Partial<Record<Category, number>>` lets you accumulate counts in `buildFacets` with a simple `(acc[key] ?? 0) + 1` pattern while staying fully typed.
