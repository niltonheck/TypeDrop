Typed Expense Splitter: Group Bills, Share Calculation & Settlement Summary

You're building the core logic for a group travel expense app. Friends log shared bills, the system splits costs by participant, and then produces a typed settlement summary showing exactly who owes whom — with the compiler enforcing every expense shape, split strategy, and debt record.

Goals

  • Define a `SplitStrategy` discriminated union with `"equal"` and `"custom"` variants, and build the `Expense`, `Settlement`, and `SplitSummary` types around it.
  • Implement `computeShares` that narrows on `split.kind` to return each participant's share in cents, correctly distributing any remainder to the first participant.
  • Implement `computeBalances` that aggregates net balances across all expenses — crediting the payer the full amount and debiting every participant their computed share.
  • Implement `settleDebts` with a greedy creditor/debtor matching loop, then compose everything in `splitExpenses` to return a complete `SplitSummary`.
challenge.ts 
// Core types you must define:

type SplitStrategy =
  | { kind: "equal" }
  | { kind: "custom"; shares: Record<string, number> };

type Expense = {
  id: string;
  description: string;
  paidBy: string;
  participants: string[];
  amount: number;       // in cents
  split: SplitStrategy;
};

type Settlement = { from: string; to: string; amount: number };

type SplitSummary = {
  balances: Record<string, number>;
  settlements: Settlement[];
};

// Functions you must implement:
declare function computeShares(expense: Expense): Record<string, number>;
declare function computeBalances(expenses: Expense[]): Record<string, number>;
declare function settleDebts(balances: Record<string, number>): Settlement[];
declare function splitExpenses(expenses: Expense[]): SplitSummary;
Hints (click to reveal)

Hints

  • Use a `kind` discriminant on `SplitStrategy` so TypeScript narrows the type inside an `if` or `switch` — no type assertions needed.
  • In `computeBalances`, initialise each person's balance with `record[name] ?? 0` before adding or subtracting to avoid `undefined` arithmetic.
  • For `settleDebts`, sort creditors and debtors by absolute value descending, then use a two-pointer / while-loop approach — settle `Math.min(credit, debt)` each iteration and discard entries whose balance drops below 1.
