Typed Shopping Cart with Discount Rules

You're building the cart engine for a small e-commerce storefront. Products come in different categories, discounts are expressed as typed rules (percentage off, fixed amount off, or buy-X-get-Y free), and the compiler must enforce every product shape, discount variant, and line-item calculation with no escape hatches.

Goals

  • Define a branded `ProductId` type and the `Category` literal union.
  • Implement `calcLineDiscount` using exhaustive narrowing over the `DiscountRule` discriminated union.
  • Implement `buildCartSummary` to correctly compute subtotal, total discount, and a non-negative total.
  • Implement `filterByCategory` as a generic function constrained to `Category`.
challenge.ts 
// Key types and main function signatures:

type Category = "electronics" | "clothing" | "food";

type DiscountRule =
  | { kind: "percentage"; percent: number }
  | { kind: "fixed"; amountInCents: number }
  | { kind: "bxgy"; buyQty: number; getQty: number };

interface CartItem {
  product: Product;   // has id: ProductId, category: Category, priceInCents: number
  quantity: number;
  discount: DiscountRule | null;
}

// Functions you must implement:
function makeProductId(raw: string): ProductId;
function calcLineDiscount(item: CartItem): number;
function buildCartSummary(items: ReadonlyArray<CartItem>): CartSummary;
function filterByCategory<C extends Category>(
  summary: CartSummary,
  category: C
): ReadonlyArray<CartItem>;
Hints (click to reveal)

Hints

  • Use a `switch` statement on `item.discount.kind` inside `calcLineDiscount` — TypeScript will narrow each branch automatically.
  • For the `bxgy` rule, the number of free units per group is `getQty`, and a group has size `buyQty + getQty`.
  • The branded type `Brand<T, B>` works by intersecting `T` with an object that has a unique symbol key — you just need to cast inside `makeProductId`.
