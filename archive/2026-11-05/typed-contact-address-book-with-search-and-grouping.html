Typed Contact Address Book with Search & Grouping

You're building the contacts module for a lightweight CRM. Raw contact records arrive from a form submission, and your job is to validate them, normalize their phone numbers, search by field, and group them — with the compiler enforcing every field shape, group key, and search result type.

Goals

  • Implement `validateContact` to narrow all `unknown` fields, collect every error, normalize email and phone digits, brand the country code, and return a discriminated-union result.
  • Implement `searchContacts` using the `StringContactField` mapped type so only string-valued Contact fields are valid search targets.
  • Implement `groupByCategory` returning a `Record<ContactGroup, readonly Contact[]>` with all four keys always present.
  • Implement `summarizeGroup` to format a human-readable bucket summary, capitalizing the group label and handling the empty-group case.
challenge.ts 

type ContactGroup = "family" | "friend" | "colleague" | "acquaintance";
type PhoneType    = "mobile" | "home" | "work";
type CountryCode  = string & { readonly __brand: "CountryCode" };

interface Contact {
  readonly id:        string;
  readonly firstName: string;
  readonly lastName:  string;
  readonly email:     string;       // lowercased + trimmed
  readonly phones:    readonly PhoneNumber[];
  readonly group:     ContactGroup;
  readonly country:   CountryCode;
  readonly fullName:  string;       // derived: "firstName lastName"
}

/** Only string-valued keys of Contact — enforced by a mapped type */
type StringContactField = {
  [K in keyof Contact]: Contact[K] extends string ? K : never;
}[keyof Contact];

export function validateContact(raw: RawContact): ValidationResult { ... }
export function searchContacts(contacts: readonly Contact[], query: SearchQuery): readonly Contact[] { ... }
export function groupByCategory(contacts: readonly Contact[]): Record<ContactGroup, readonly Contact[]> { ... }
export function summarizeGroup(group: ContactGroup, contacts: readonly Contact[]): string { ... }

Hints

  • For `StringContactField`, a mapped type with a conditional (`extends string ? K : never`) plus an indexed lookup (`[keyof Contact]`) will distribute over all keys automatically.
  • Brand `CountryCode` by casting through an intersection — but remember you can't use `as`; consider a helper function with an explicit return type of `CountryCode` that validates the format first.
  • For `groupByCategory`, seed your accumulator with all four `ContactGroup` keys mapped to `[]` using `Object.fromEntries` or a typed initial value satisfying `Record<ContactGroup, Contact[]>`.
