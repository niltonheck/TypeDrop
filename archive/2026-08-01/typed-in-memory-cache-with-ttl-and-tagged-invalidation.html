Typed In-Memory Cache with TTL & Tagged Invalidation

You're building the caching layer for a multi-tenant SaaS dashboard. Data from different domains (users, products, reports) is fetched expensively and must be cached with per-entry TTLs, but operations teams also need to bulk-invalidate all entries belonging to a logical tag (e.g. wipe every "tenant:acme" entry at once). The hardest part is keeping the cache fully generic and type-safe across heterogeneous value shapes.

Goals

  • Define a branded `CacheKey` type and implement `toCacheKey` without using `as` or unsafe assertions.
  • Implement `createCacheStore<Schema>()` so that `get` returns `CacheResult<Schema[K]>` inferred from the domain key — not `CacheResult<unknown>`.
  • Implement TTL expiry in `get` (returning `reason: 'expired'`) and bulk `invalidateTag` that removes all tagged entries and returns the count.
  • Implement the `getOrFetch` helper that transparently serves from cache on hit and populates the cache via the async `fetcher` on miss.
challenge.ts 
// Key types you'll work with:

type CacheKey = string & { readonly __brand: "CacheKey" };

type CacheEntry<V> = {
  value: V;
  expiresAt: number;
  tags: ReadonlyArray<string>;
};

type CacheResult<V> =
  | { hit: true;  value: V }
  | { hit: false; reason: "missing" | "expired" };

// The main generic interface — Schema maps domain names to value types:
// e.g. { user: User; product: Product }

interface CacheStore<Schema extends Record<string, unknown>> {
  set<K extends keyof Schema>(
    domain: K, id: string, value: Schema[K],
    ttlMs: number, tags?: string[]
  ): CacheKey;
  get<K extends keyof Schema>(domain: K, id: string): CacheResult<Schema[K]>;
  invalidate(key: CacheKey): boolean;
  invalidateTag(tag: string): number;
  size(): number;
}

Hints

  • For `toCacheKey` without `as`: give the function an explicit `: CacheKey` return type annotation — TypeScript will accept the assignment because the brand is structurally added by the annotation, not asserted away.
  • The backing `Map` can store `CacheEntry<unknown>` internally; the public `get` method casts through the generic `K` constraint (`Schema[K]`) so callers see the correct type without any unsafe escape hatch.
  • For `invalidateTag`, iterate `map.entries()` and collect keys to delete in a separate array first — mutating a Map while iterating it is unsafe in some runtimes.
