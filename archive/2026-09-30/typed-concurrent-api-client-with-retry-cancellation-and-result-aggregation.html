Typed Concurrent API Client with Retry, Cancellation & Result Aggregation

You're building the data-fetching layer for a distributed dashboard that fans out requests to multiple third-party microservices simultaneously. Each endpoint has its own response shape, requests must be cancellable, failed requests are retried with exponential back-off, and the final aggregated report is a discriminated-union result per endpoint — all enforced by the compiler with zero `any`.

Goals

  • Define `Result<T,E>` and `FetchError` as discriminated unions, then derive `EndpointResponse` with `infer` and `AggregatedResults` with a mapped type.
  • Implement `fetchWithRetry` with abort-signal checking, parse-error short-circuiting, and exponential back-off retries gated by a `shouldRetry` predicate.
  • Implement `fetchAll` that fans out all endpoints concurrently via `Promise.allSettled`, wires a single global `AbortController` timeout, and returns a fully-typed `AggregatedResults<M>`.
  • Implement the three result helpers — `isOk` (type guard), `unwrapOr` (with `F extends T`), and `mapResult` — without any unsafe casts.

Hints (click to reveal)

Hints

  • For `EndpointResponse`, write `E extends Endpoint<infer T> ? T : never` — the compiler will unpack the generic parameter for you.
  • In `fetchAll`, `Promise.allSettled` returns `PromiseSettledResult<Result<T, FetchError>>[]`; a `.rejected` settlement (which shouldn't normally happen) can be mapped to a `{ kind: 'network', message: ... }` err.
  • To build `AggregatedResults<M>` at runtime inside `fetchAll`, accumulate into a `Partial` record and cast with `as AggregatedResults<M>` only at the final return — that's the one place a cast is acceptable because you've verified all keys.
