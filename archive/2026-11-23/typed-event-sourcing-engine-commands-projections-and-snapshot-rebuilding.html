2026-11-23 Hard

Typed Event Sourcing Engine: Commands, Projections & Snapshot Rebuilding

You're building the core of an event-sourced order management system. Raw commands arrive as `unknown` JSON, are validated into a discriminated-union command type, applied to produce typed domain events, and then replayed (with optional snapshot checkpoints) to rebuild the current aggregate state — the compiler must enforce every command shape, event variant, state transition, and projection result.

Goals

  • Implement `validateCommand` to safely narrow `unknown` JSON into a typed `DomainCommand`, returning structured `CommandValidationError` variants for every invalid shape.
  • Implement `applyEvent` with exhaustive, compiler-enforced handling of all five `DomainEvent` variants, enforcing legal state transitions and returning `ApplyError` on violations.
  • Implement `replayEvents` to reconstruct `OrderState` by folding events in sequence order, optionally seeding from a `Snapshot` and skipping already-applied events.
  • Implement both projections (`projectOrderTotal`, `projectEventLog`) and `buildSnapshot` using only the typed state and event arrays — no casting or escape hatches.
challenge.ts 

// Core types at a glance
type OrderId   = Brand<string, "OrderId">;
type EventSeq  = Brand<number, "EventSeq">;

type OrderState = {
  readonly orderId: OrderId;
  readonly status: "Draft" | "Confirmed" | "Cancelled";
  readonly items: ReadonlyArray<OrderLineItem>;
  readonly lastSeq: EventSeq;
};

type Snapshot = { readonly atSeq: EventSeq; readonly state: OrderState };

// Mapped type: one typed handler per command variant
type CommandHandlerMap = {
  [K in DomainCommand["type"]]: (
    cmd: Extract<DomainCommand, { type: K }>,
    state: OrderState | undefined
  ) => Result<DomainEvent, ApplyError>;
};

// Key functions you must implement
declare function validateCommand(raw: unknown): Result<DomainCommand, CommandValidationError>;
declare function applyEvent(state: OrderState | undefined, event: DomainEvent): Result<OrderState, ApplyError>;
declare function replayEvents(events: ReadonlyArray<DomainEvent>, snapshot?: Snapshot): Result<OrderState, ApplyError>;
declare function projectOrderTotal(state: OrderState): number;
Hints (click to reveal)

Hints

  • In `validateCommand`, narrow `unknown` step by step: check `typeof raw === 'object'`, then `'type' in raw`, then use a `switch` on `raw.type` — TypeScript will not narrow `unknown` automatically.
  • The `CommandHandlerMap` mapped type means you can dispatch `handlers[cmd.type](cmd, state)` — but you'll need a small type assertion bridge or a generic helper to satisfy the compiler that `cmd` matches the handler's parameter type; think about `Extract<DomainCommand, { type: typeof cmd.type }>`.
  • In `replayEvents`, filter events to only those with `event.seq > (snapshot?.atSeq ?? -1)` before folding, then use `applyEvent` as the reducer — short-circuit on the first `Err` result.
